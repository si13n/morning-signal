WSO2 Agent Manager reaches GA for enterprise agent governance

WSO2 announced general availability of Agent Manager, an open control plane that provides identity, governance, observability, and operational controls for AI agents running across frameworks and runtimes.

Why it matters

Teams deploying test-design or test-execution agents gain a single governance plane to enforce identity, audit, and operational invariants for agentic QA workflows at scale.

Agentic QA / Test automation2/10

DoorDash published a production multi-agent LLM system for feature-flag cleanup

DoorDash described a two-phase agentic pipeline (analysis + parallel cleanup agents) that produces merge-ready PRs for stale feature flags; the system validates builds, tests, patch coverage, and static analysis before opening PRs.

Why it matters

This is a concrete production example of agents executing code changes with CI-level validation and human checkpoints — a template QA teams can adapt for safe, automated remediation workflows.

AI-assisted testing / Code review3/10

Alibaba open-sources OpenCodeReview — an agentic, deterministic-first code-review CLI

OpenCodeReview is a Go-based CLI that combines deterministic pipelines (file selection, rule matching) with an LLM agent for dynamic analysis; it ships benchmarks and prioritizes precision via deterministic components.

Why it matters

QA and engineering-review pipelines can adopt a hybrid deterministic/agent approach to improve review precision while keeping AI-driven analysis auditable and reproducible.

JetBrains adds /demo to Junie CLI to record agent-driven UI demos and smoke tests

Junie’s /demo mode builds and launches apps in Docker, drives the UI via a model with Computer Use capability, records video/screenshots, and generates an HTML report for reviewer inspection and CI integration.

Why it matters

Provides structured, reviewable evidence from agent-driven UI runs; useful for release smoke tests, reviewer sign-off, and making agent results auditable in PRs and CI artifacts.
