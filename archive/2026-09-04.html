GitHub Actions adds a runner-deprecation REST API and finer workflow permissions

GitHub Actions added GET /actions/runners/deprecations/{version} to show registration/runtime deprecation dates; workflows also get a new vulnerability-alerts GITHUB_TOKEN permission and new job context properties for reusable workflows.

Why it matters

Runner-deprecation visibility helps QA own runner-version compatibility and avoid brownouts; vulnerability-alerts reduces scope creep for security-aware test workflows.

Playwright 1.62 (1.62.1 patch) folds MCP/agent tooling in and adds 'isolated' retries

Playwright's 1.62 line bundles the MCP server/CLI, introduces an 'isolated' retry strategy to isolate flaky tests from concurrency-related failures, and improves diagnostics and reporter hooks.

Why it matters

Bundled MCP lowers friction for running LLM/agent-driven test generation and execution; isolated retries reduce false positives and improve flaky-test triage workflows.
