Junie adds /demo mode — agentic UI demos with video, report, and CI integration

JetBrains’ Junie CLI introduced /demo: an agent mode that builds, launches, and interacts with apps using Computer Use-capable models, producing video, screenshots and an HTML report that can be stored as CI artifacts.

Why it matters

GitHub’s Changelog: the REST API now supports the 'Restrict code coverage' ruleset option so teams can programmatically create, read and update minimum coverage or maximum drop conditions for PRs.

Why it matters

Enables enforcing coverage-based quality gates at scale via infra-as-code and pipeline automation, improving consistency across many repositories.

CI / Test Infrastructure2/10

Workflow execution protections for Actions generally available

GitHub made workflow execution protections generally available, letting organizations define allowlists to control who or what events can trigger Actions workflows.

Why it matters

QA teams can restrict who triggers expensive or release-scoped test suites, reducing accidental or malicious workflow runs and improving test-run predictability.

Test Automation Security2/10

Stage-only npm tokens for safer automation

GitHub adds 'Read and write (stage only)' for npm granular access tokens so automation can stage package versions for review without full publish privileges.

Why it matters

Reduces credential blast radius for build and release automation used in test pipelines and package-based smoke tests, improving safety of automation credentials.
