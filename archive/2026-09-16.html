Test infrastructure / Resource determinism2/10

Kubernetes v1.37: Memory QoS graduates to Beta (enabled by default)

Kubernetes v1.37 graduated Memory QoS to Beta and enables it by default on cgroup v2, using requests/limits to protect requested memory and throttle before hard OOM limits.

Why it matters

Memory QoS changes how test nodes behave under contention—QA should revalidate node sizing, flaky-test thresholds, and test concurrency assumptions under the new defaults.

Test infrastructure / Scheduling determinism3/10

Kubernetes v1.37: Pod-Level Resource Managers graduate to Beta

Pod-Level Resource Managers in Kubernetes v1.37 let Kubelet components (Topology, CPU, Memory managers) use pod-level resource declarations for hardware placement decisions.

Why it matters

Improved pod-level placement reduces scheduling-induced variability in parallel test runs and helps QA achieve more reproducible test-node placement and timing.

Test infrastructure / Control-plane reliability3/10

Kubernetes v1.37: etcd RangeStream cuts memory use for large list reads

etcd RangeStream graduated to Beta in v1.37, lowering memory consumption during large list reads and improving API-server scalability for clusters with many objects.

Why it matters

Device farms and large test farms that list many API objects will see lower control-plane memory spikes, reducing control-plane–caused test failures and instability.
