Android Bench 2.0 introduces challenging long‑horizon tasks, a multimodal visual judge, multi‑harness evaluations, and continuous completion metrics to measure how LLMs and agents help with real Android engineering work.

AndroidX Security State libraries provide a unified device security and update view

AndroidX Security State (stable) and Security State Provider (1.0.0) expose standardized APIs to report device security posture and pending OS/patch availability across OEMs and providers.

CI test infrastructure3/10

Ubuntu 26 runner image for GitHub Actions is generally available (x64 and arm64)

GitHub Actions now supports Ubuntu 26.04 runner images in GA for both x64 and arm64, graduating from public preview and replacing older Ubuntu runner images on the hosted fleet.

Why it matters

Test matrices, toolchains, and dependency packaging can behave differently on Ubuntu 26 or arm64; QA leads should validate CI images, pin critical tool versions, and update reproducibility tests.

CI security & workflow governance2/10

Workflow execution protections for GitHub Actions reach general availability

GitHub made workflow execution protections generally available: actor/event allowlists, workflow-file targeting, Insights, and a REST API — plus a default evaluate-mode rule to disable pull_request_target for public repos.

Why it matters

Policy enforcement can silently block or change who can run tests; QA should run evaluate mode, audit impacted workflows, and update gating and allowlists to avoid unexpected CI failures.
