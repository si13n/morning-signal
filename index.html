Cloudflare Traces (open beta) — proxy-layer requests as OpenTelemetry spans

Cloudflare launched Traces in open beta, converting proxy, security rules, cache, routing and origin handling into OpenTelemetry spans and exporting them via OTLP to observability backends.

Why it matters

Makes edge/proxy behavior visible to test traces, aiding end-to-end test failure triage and flaky-test investigation across CDN/proxy boundaries.
