Grafana Turns Cypress Test Results Into Persistent Observability Data

Grafana Labs published a pattern to export Cypress lifecycle data to Prometheus (via Pushgateway) and ingest it into Grafana Cloud, creating time-series metrics for individual tests, specs, durations, failure rates and flaky frequency across runs.

Why it matters

Makes test reliability and performance observable alongside app telemetry, enabling trend detection, flaky-test triage, and alerting for suite degradation rather than relying on ephemeral CI logs.

Web Performance Testing / Observability2/10

Measuring the back/forward cache with Application Metrics

Sentry released bfcacheMetricsIntegration (JS SDK v11) to model bfcache hits, misses, reasons and reload cost as application metrics so teams can chart back/forward cache health and investigate regressions by route.

Why it matters

Closes a visibility gap: QA can detect regressions that standard performance tools miss, prioritize fixes by route/release, and quantify user impact of bfcache misses.

Testing Practices / Agentic QA3/10

Professional skepticism is a dev’s best skill

Stack Overflow’s post/interview with BrowserStack’s David Burns argues for professional skepticism when using AI/agents, recommends applying TDD principles to agentic workflows, and focuses flaky-test fixes on controlling application state and isolation.

Why it matters

Reinforces disciplined test design and skepticism for teams using agents; practical guidance to reduce flaky tests and validate agent-produced test assets or fixes.

Agentic QA / Autofix3/10

Agentic autofix now uses Copilot Memory

GitHub updated its agentic autofix so, when enabled, autofix agents consult Copilot Memory for contextual clues before proposing fixes — surfacing prior recommendations or repo-specific context into automated remediation.

Why it matters

Autofix behavior now depends on persisted memory; QA must validate agent-applied patches, add tests guarding autofix changes, and audit memory-influenced fixes to prevent regressions or nondeterministic outcomes.

CodeQL 2.27.1 adds C/C++ queries and Kotlin 2.4.20 support

GitHub released CodeQL 2.27.1 with new queries for C and C++, Kotlin 2.4.20 support, and query-accuracy improvements to code scanning and analysis pipelines.

Why it matters

Expands static-analysis coverage for native and Kotlin code; QA teams should upgrade scanners, revise rulesets, and retune suppression to reduce false positives and coverage gaps.

Mobile QA / Agentic Testing4/10

Build your way: Use any AI agent of your choice in Android Studio

Android Studio added first-class support for third-party AI agents (agent mode) with access to build diagnostics, emulators, SDK tools and test execution, enabling agents to run, diagnose, and triage mobile tests inside the IDE.

Why it matters

Enables agentic test design and local triage for mobile teams; QA must validate agent sandboxing, ensure reproducible runs, and add audit trails for agent-driven test actions.
