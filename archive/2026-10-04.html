GitHub Actions: macOS 14 runner image retirement

GitHub will retire the macOS 14 (Sonoma) Actions runner image on November 2, 2026; jobs using that image will fail during scheduled removal windows. The changelog gives migration guidance and timing.

Why it matters

If you run macOS or iOS tests on GitHub Actions, update runner images and validate macOS build/test pipelines before Nov 2 to avoid failing test runs and blocked releases.

Android CLI adds Device Streaming and Android skills

Android CLI now supports Android Device Streaming (secure ADB-over-SSL) and a growing 'Android skills' repo. Agents and CLIs can reserve real devices, deploy builds, collect logs/traces, and capture headless screenshots from the terminal.

Why it matters

Enables agent-driven remote device access for automated end-to-end tests, screenshot suites, and trace-backed debugging without separate device-farm APIs or custom adapters.

Closed-loop incident response: connect AWS DevOps Agent to OpenSearch

AWS published a how‑to connecting AWS DevOps Agent to Amazon OpenSearch via the Model Context Protocol (MCP), enabling alerts to auto-trigger agent investigations using observability data and structured payload mapping.

Why it matters

Makes autonomous root-cause investigations practical for test-failure alerts and production regressions — useful for automating triage of flaky tests and release-blocking failures.

Seer, the Sentry MCP and CLI, or your own coding agent: where each one fits

Sentry explains tradeoffs between Seer (Sentry’s coding agent), the Model Context Protocol (MCP), and CLI-based workflows for automating error triage, structured context delivery, and scripted fixes in CI and incident pipelines.

Why it matters
