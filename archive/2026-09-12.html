Test observability2/10

Kubernetes v1.37: native histograms graduate to Beta (enabled by default)

Kubernetes v1.37 graduates Prometheus Native Histograms to Beta and enables them by default, offering higher-resolution latency/duration metrics with lower cardinality and reduced telemetry overhead compared with classic histograms.

Why it matters

Higher-resolution, lower-cardinality metrics improve test telemetry accuracy and make failure triage, flaky-test correlation, and performance test analysis more reliable.

Mobile QA / CI runners3/10

Xcode 27 runner image now runs on macOS 27 (public preview)

GitHub-hosted macOS runner image for Xcode 27 now runs on macOS 27 (public preview). Workflows continue to use runs-on labels like `xcode-27`; the image runs on arm64 macOS runners only.

Why it matters

QA teams must validate iOS/macOS test matrices and CI workflows against macOS 27 and arm64 runners to avoid test environment drift and broken signing or simulator behaviours.
