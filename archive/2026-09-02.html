Copilot code review now surfaces an approval assessment and — when enabled by admins — can submit approvals that count toward repository required-approvals rules (feature in public preview and off by default).

Copilot as a merge gate changes QA review workflows and governance; teams must update policies, auditability, and required-approvals configuration before enabling automated approvals.

Test Infrastructure / Platform QA3/10

Kubernetes v1.37: etcd RangeStream (beta) reduces API server memory on large list reads

Kubernetes v1.37 promotes etcd RangeStream (beta) which streams large etcd reads in chunks (requires etcd v3.7), lowering memory spikes during watch-cache initialization and large list requests.

Why it matters

Test clusters and platform teams can expect reduced OOM risk and more predictable memory during large e2e or scale tests; verify etcd version and feature-gate to use RangeStream.
