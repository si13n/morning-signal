Android Bench 2.0 adds long‑horizon tasks and agentic evaluation

Google upgraded Android Bench to 2.0 with long‑horizon tasks, continuous scoring, and agent-level evaluations to measure LLMs and agents on multi‑day, multi‑step Android engineering work. The leaderboard and methodology were updated.

Agentic QA / AI-assisted testing tools2/10

Junie Local: JetBrains ships a fully on‑device coding agent

JetBrains released Junie Local (on‑device Junie) that runs a tuned Qwen3.6‑27B model on M5 Macs (64GB RAM). It runs the same agent loop locally, removing network/tokens and enabling private, unlimited agent runs.

Why it matters

Local agents let QA run many iterations privately, reduce cost of repeated test-generation tasks, and enable offline, NDA‑safe experimentation with agentic test flows.

Agentic QA / Test execution2/10

Junie /demo: a reproducible demo VM for agentic UI testing and video evidence

Junie’s /demo mode provides a reproducible demo VM template (demo‑base image + tooling) that agents can use to launch apps, drive UI, capture screenshots, video, and HTML reports for review.

Why it matters

Makes agentic UI runs auditable and repeatable — useful for automated exploratory flows, regression video evidence, and machine‑reviewable test artifacts in QA pipelines.

Test governance / Quality gates2/10

GitHub adds REST API to manage 'Restrict code coverage' ruleset

GitHub now exposes a REST API to create, read, and update the 'Restrict code coverage' repository ruleset option, enabling programmatic enforcement of minimum coverage or maximum PR coverage drop.

Why it matters

QA leads can now enforce coverage gates across many repos via infrastructure-as-code, automating coverage thresholds and integrating coverage policy into release pipelines.

Mobile QA / Device testing3/10

AndroidX Security State libraries provide component‑level device patch posture

AndroidX Security State (v1.1.0) and Security State Provider (v1.0.0) expose component‑level patch and update status so apps can programmatically query OS/module/kernel patch posture instead of a single SPL value.

Why it matters

Mobile QA can now gate features, simulate patch states, and validate enterprise flows against real component‑level device security posture for more accurate device compatibility testing.

Performance testing / LLM benchmarking2/10

NVIDIA publishes AIPerf for realistic, high‑concurrency LLM inference benchmarking

NVIDIA introduced AIPerf (replacing GenAI‑Perf), a multiprocess LLM benchmarking tool that avoids client bottlenecks, supports 15+ endpoint types, and uses public datasets and trace replays for realistic workloads.

Why it matters

QA and SRE teams evaluating LLM‑backed test agents can use AIPerf to measure latency, throughput, concurrency, and detect client-side bottlenecks under realistic traces.
