Top Signal Priority 1/10

Grafana's gcx CLI and MCP server reach GA to let coding agents query live telemetry

Grafana Labs announced general availability for two integrations—gcx (a CLI for custom agent workflows) and a more opinionated Grafana MCP server—that let AI coding agents read metrics, logs, traces, SLOs and Synthetic Monitoring from Grafana Cloud or self-hosted Grafana. Grafana also published agent skill bundles and Claude Code plugins to make telemetry available to agents during development and local iteration.

Why it matters

QA and test automation teams can now ground agent-generated changes in real production telemetry: agents can derive realistic latency and request distributions for unit/integration tests, author k6 load scripts from observed traffic, and update dashboards or test mocks automatically. That improves test realism, reduces false positives from unrealistic mocks, and gives a practical path to include observability data in agentic SDLC checks.
