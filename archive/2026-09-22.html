The Agent Harness: Control Planes, Invariants, and Approval Boundaries for Production AI Agents

Vinoth Govindarajan (OpenAI) explains common production-agent failures and prescribes harness controls: single-owner state, ordered commits, scoped execution, and provable receipts to avoid silent, unrecoverable state losses.

GitHub deprecates all-platform CodeQL bundle

GitHub marked the all-platform CodeQL bundle deprecated in CodeQL CLI 2.27.0 and will remove it in mid‑March 2027; teams must switch to platform-specific downloads (including ARM64) before removal.

Why it matters

Automation that fetches the all-platform bundle will break CI code-scanning; update pipeline scripts, installers, and artifact mirrors to avoid scan failures.

Observability for AI/Agent Testing2/10

Sentry adds zero-config Agent Tracing for Laravel AI

Sentry shipped a laravel integration (sentry-laravel 4.27) that auto-instruments Laravel AI: it matches LLM HTTP requests to agent tool calls and surfaces conversations, tool inputs/outputs, and trace evidence in Explore.

Why it matters

Makes failure triage, tool-call debugging, and E2E agent test evidence collection straightforward for PHP apps — useful for flaky-agent analysis and regression investigations.

AI Testing & Evaluation3/10

Microsoft: 'Knowledge cutoff is a poor proxy for model capability'

Microsoft research shows a model's stated knowledge-cutoff date does not reliably indicate what it actually knows about a product; results vary by task and version, producing mixed passes and failures.

Why it matters

QA teams validating agents should create representative task suites and controlled baselines rather than relying on cutoff dates to decide what to test or provide as context.

AI-assisted Testing & Code Review3/10

OpenCodeReview: deterministic, agent-based AI code review (paper + OSS)

Alibaba's OpenCodeReview (paper + open-source) describes a deterministic pipeline for agent-based code review that injects determinism at key pipeline points to make reviews reproducible and auditable.

Why it matters

Deterministic review pipelines help QA make LLM-driven code-review outputs testable, reproducible, and suitable for gating and audit trails in automated workflows.
